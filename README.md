# 电子基盘 (Electron Base) — 街机 1:1 复刻 & 1v1 实时联网对战版

基于开源项目 [`weimzh/mahjong`](https://github.com/weimzh/mahjong) 完整 C++ 引擎（`CGame` / `CPlayer` / `CBot` / `CTitle` / `CSound` / `CMusic`）与原版街机位图、音效、音乐、字体资源进行 **1:1 像素级（640×480）HTML5 Canvas 移植**，并在此基础上完整实现了 **PRD 4.1 触控与手势体系、4.4 掼蛋级一链入房 1v1 实时联网对战、以及 4.6 WebRTC P2P 实时语音对讲与智能音频闪避系统**。

---

## ✨ 核心特性一览

### 1. 原汁原味街机 1:1 像素级复刻（离线单机 PVE）
- **原版 640×480 街机画布渲染**：100% 还原原版坐标布局（对家手牌、17 列牌河、宝牌指示牌、火苗 `fire1/2`、闪电 `flash1/2`、手部光标 `hand.bmp`、选角/过关立绘 `mjgirl1~4`、灰度渐隐揭幕动画）。
- **原版役种与番数算法**：完整移植日本立直麻将 / 电子基盘番种判定（立直、门前清自摸、平和、断幺九、役牌、混一色、清一色、七对子、大三元、国士无双、四暗刻、九莲宝灯等）及天胡、换牌作弊指令（`DONDEN`）。
- **原版语音与配乐**：内置 11 首 `.ogg` 原声背景音乐与 11 组 `.wav` 吃/碰/杠/立直/自摸/胡牌/投币音效，内嵌文鼎楷体（`gkai00mp.ttf`）与毛笔字体（`brush.ttf`）。

### 2. 触控、手势与防误触交互体系（PRD 4.1）
- **单击选牌 & 预览**：单击手牌使牌面高亮锁定。
- **上滑出牌（Swipe-Up > 30px）**：按住任意手牌向上滑动超过 `30px` 即可顺滑打出，松手低于阈值自动吸附回位防误触。
- **双击快出（Double-Tap < 350ms）**：在已选中手牌上 `350ms` 内再次点击立即打出。
- **横向滑选（Hover Scrubbing）**：手指/鼠标在手牌区横向滑动时连续跟随高亮对应手牌。
- **动态动作气泡（Action Bubbles）**：轮到玩家决策时，画布底部自动弹出醒目的胶囊气泡（`胡 RON`、`听 REACH`、`杠 KONG`、`碰 PUNG`、`吃 CHOW`、`换牌 DONDEN`、`弃牌跳过`）。

### 3. 公网跨网直连 & 2人/4人麻将双模式对战（PRD 4.4 增强版）
- **零门槛即开即玩**：打开页面无需注册登录，0 秒直接进入单机 PVE 牌桌与街机 AI 对弈。
- **免服公网直连（Public WSS + LAN SSE + 本地三通道容灾）**：
  - 内置零配置公网 MQTT over WSS 信令集群直连通道，支持异地宽带、手机 4G/5G 流量或部署至 GitHub Pages 静态站点后，直接通过 **6 位房间号** 或 **邀请链接** 跨公网秒级组局。
- **支持「🀄 四人环桌麻将 (4P)」与「⚔️ 二人街机死斗 (2P)」双模式**：
  - **四人麻将模式 (4P)**：支持 `1~4 名真人 + 空位由街机 AI 自动补齐`（如 2 真人 + 2 电脑 AI 即可开局四人东南西北环桌麻将），完整实现四人逆时针摸打、中央罗盘记分板、以及 **荣和 (胡) > 杠/碰 > 下家吃** 的四人鸣牌优先级仲裁与三家分摊点数结算。
  - **二人街机死斗 (2P)**：100% 还原原版电子基盘二人对坐与 17 列牌河体验。
- **联网防作弊锁定 & 房间规则可选**：
  - 进入联网模式后，左侧单机秘技菜单自动切换为 **「🏆 联机风位战况榜」**，自动锁定破坏同步的单端改牌/加分功能；
  - 建房支持选择 **「🏆 公平竞技（严禁 DONDEN 换牌）」**（默认）或 **「🎪 街机娱乐（1v1 允许每局 1 次 DONDEN 互换手牌）」**；
  - 右侧角色切换在联网模式下自动变为 **「切换我的出战代表角色」** 并实时同步给全房玩家。

### 4. WebRTC P2P 实时语音对讲与智能音频闪避（PRD 4.6）
- **进房默认开麦**：进入联机房间后自动协商 WebRTC P2P 音频流（开启硬件级回声消除 `echoCancellation`、降噪 `noiseSuppression`、自动增益 `autoGainControl`）。
- **悬浮语音胶囊控制**：顶部状态栏常驻 `🎙️ 开麦中 / 🔇 已闭麦` 与 `🔊 听筒:开 / 🔈 听筒:关` 一键切换按钮，支持无麦克风自动降级为只听模式。
- **实时声波光环（Speaking Indicator）**：基于 `AudioContext` RMS 音频能量分析，说话方状态胶囊自动浮现翠绿色呼吸波纹动画。
- **BGM 智能音频闪避（Smart Audio Ducking）**：检测到任意一方说话或发送快捷语音时，街机背景音乐自动从 `0.75` 平滑压低至 `0.20`（约 `-8dB`）；说话结束 `1秒` 后平滑恢复原音量，确保人声清晰不吵杂。
- **快捷语音指令（Web Speech TTS）**：左侧联机面板内置 6 条经典麻将快捷语音（*“快点儿吧，我等到花儿都谢了！”*、*“哈哈，这把牌我听牌啦！”* 等），无物理麦克风也可直接测试语音对讲与 BGM 闪避效果。

## 🚀 快速启动与联机测试指南

### 1. 安装依赖与启动开发服
```bash
npm install
npm run dev
```
启动后浏览器访问：**`http://localhost:3000/`**

### 2. 单机双窗口 1v1 联机测试（最快捷）
1. 打开 `http://localhost:3000/`，点击顶部右侧的橙色胶囊按钮 **「🤝 邀请好友对战」**。
2. 在弹出的联机大厅中选择喜欢的 **对战角色立绘（A ~ D）** 和 **单局底注筹码**。
3. 点击弹窗底部的 **「🖥️ 双开窗口测试联机」** 按钮（或复制链接在新标签页打开）。
4. 两个窗口将自动建立 1v1 房间连接与 WebRTC 语音通道：
   - 房主窗口为 **先手（东家）**，客机窗口为 **后手（西家）**。
   - 双方在各自窗口轮流出牌、吃/碰/杠/立直/自摸/荣和，实时同步牌河与筹码结算。
   - 点击左侧面板的 **「快捷语音互动」** 按钮，可直观体验跨窗口实时语音播报与 **「📉 BGM闪避」** 效果。

### 3. 局域网多设备（手机 / 平板 / 另一台电脑）联机
1. 确保两台设备连接在同一个 Wi-Fi / 局域网下。
2. 在电脑端点击 **「🤝 邀请好友对战」**，复制弹窗中显示的 **「局域网 / 手机 Wi-Fi 对战链接」**（如 `http://192.168.x.x:3000/?room=XXXXXX&girl=1&bet=10`）发送到手机或另一台电脑浏览器打开即可直接对战。

### 4. 构建生产版本
```bash
npm run build
```
构建产物将输出至 `dist/` 目录（同时已打包生成 `dist_updated.zip`）。
