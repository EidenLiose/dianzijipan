# 电子基盘 (Electron Base) — 街机 1:1 复刻 & 公网 2P/4P 实时联机版

基于开源项目 [`weimzh/mahjong`](https://github.com/weimzh/mahjong) 完整 C++ 引擎（`CGame` / `CPlayer` / `CBot` / `CTitle` / `CSound` / `CMusic`）与原版街机位图、音效、音乐、字体资源进行 **1:1 像素级（640×480）HTML5 Canvas 移植**，并在此基础上完整迭代了 **触控与防误触手势体系、免服务器公网跨网联机、四人环桌麻将模式（支持 1~4 真人 + AI 自动补位）、联网防作弊规则管控、以及 WebRTC P2P 实时语音对讲与智能音频闪避系统**。

- **GitHub 仓库**：[`https://github.com/EidenLiose/dianzijipan`](https://github.com/EidenLiose/dianzijipan)
- **公网专属域名**：[`https://mj.eduready.ai`](https://mj.eduready.ai)（服务器：`173.231.53.226`）

### 🚀 `v3.0.0` — 公网跨网直连、四人麻将模式 (4P) & 联网防作弊管控版
1. **🌐 免服公网跨网联机（Public WSS + 局域网 SSE + 本地三通道容灾）**：
   - 在 [`src/weimzh/pvpManager.ts`](./src/weimzh/pvpManager.ts) 中内置零配置 **MQTT v3.1.1 over WSS 公网加密信令客户端 (`PublicWssSignaling`)**，自动连接高可用公网集群（`wss://broker.emqx.io:8084/mqtt` / `wss://broker.hivemq.com:8884/mqtt`）。
   - 支持异地宽带、手机 4G/5G 流量或纯静态部署（如 GitHub Pages / Vercel）下，通过 **点击邀请链接** 或 **直接输入 6 位房间号** 秒级跨公网入房。
   - 实现公网 WSS、局域网 SSE（`/api/room/*`）、同机 `BroadcastChannel` 三通道并行收发与 `msgId` 幂等去重。
2. **🀄 四人环桌麻将模式（2P 街机死斗 / 4P 东南西北双模式切换）**：
   - 新增 **4P 四人环桌麻将引擎**（[`src/weimzh/player.ts`](./src/weimzh/player.ts) 中的 `NewRound4P` / `DrawTable4P` / `PlayRound4P`）。
   - **灵活组局（1~4 名真人 + 空位 AI 自动补齐）**：4 人房间内无论有 1、2、3 还是 4 名真人，房主均可随时开局，空缺席位由街机 AI（美纪/留美/结衣/雅子）基于房间共享种子自动同桌补位对战。
   - **640×480 四向环桌渲染**：下家（本机大尺寸立牌）、右方（下家纵列）、上方（对家暗牌）、左方（上家纵列）四向牌河与中央东南西北罗盘记分板实时渲染。
   - **四人鸣牌优先级仲裁与结算**：完整实现逆时针摸打流转，出牌响应遵循 **荣和 (胡) > 大明杠 / 碰 > 下家吃** 优先级裁决；支持四人自摸三家分摊与放铳独付结算。
3. **🔒 联网模式防作弊锁定与「换牌 / 换人 / 彩蛋」规范化管控**：
   - **单机随机彩蛋自动屏蔽**：联网模式下引擎层自动屏蔽 `BonusGame`（配牌出血时钟）、`SanGenRush`（三元特快）、`FirstChance`（开局换牌）、`ReachBonus`（立直必自摸）、`LastChance`（海底捞月三选一），确保全员 136 张牌山绝对同步。
   - **左侧秘技菜单自动切换**：进入联网模式后，左侧「🕹️ 街机秘技 & 彩蛋开关」自动隐藏并切换为 **「🏆 联机风位战况榜」**，彻底封堵单端「立即胡牌（改牌）」与「投币加分」导致的双端不同步。
   - **DONDEN 换牌房间规则化**：建房弹窗提供 **「🏆 公平竞技（默认禁止 DONDEN 换牌）」** 与 **「🎪 街机娱乐（仅限 1v1 每局允许 1 次 DONDEN 互换手牌）」** 开关；公平规则下右侧换牌按钮与 `Y` 键自动锁定。
   - **换人（角色切换）与过关彩蛋同步**：联网模式下点击右侧 A~D 角色将更新**玩家自己的出战代表形象**并同步至全房，不再覆盖本地牌桌状态；一方点数归零时播放胜负过关立绘并自动开启下一局联机，不退回单机选关画面。

### 🤝 `v2.0.0` — 掼蛋级「一链入房」1v1 联网对战 & WebRTC 实时语音版
1. **🤝 零门槛即开即玩 & 一链入房（PRD 4.4）**：
   - 打开网页无需注册登录，0 秒直接进入单机 PVE 牌桌与电脑 AI 对弈。
   - 点击顶部 **「🤝 公网/好友联机」** 胶囊按钮一键生成 6 位房间号与专属对战链接并自动复制到剪贴板，支持选择代表角色（A~D）与单局底注筹码（10~99 币/番）。
   - **PVE $\rightarrow$ PVP 无缝热切换**：好友进房时顶部弹出绿色横幅提示，支持「⚡ 立即开局」或「🀄 打完当前手自动切换」。
   - **确定性牌山种子（Mulberry32）与帧同步**：在 [`src/weimzh/titles.ts`](./src/weimzh/titles.ts) 中实现 `setGameSeed`，确保联机各方 136 张牌山与宝牌 100% 一致。
   - **30 秒断线重连保护 & 一键 AI 托管接管**：对手掉线时触发 30 秒重连倒计时，支持随时点击「🤖 立即由电脑 AI 托管接管」无缝继续残局。
2. **🎙️ WebRTC P2P 实时语音对讲与智能音频闪避（PRD 4.6）**：
   - **进房默认开麦**：进入房间后自动协商 WebRTC P2P 音频流（开启硬件级回声消除 `echoCancellation`、降噪 `noiseSuppression`、自动增益 `autoGainControl`），支持多路网格语音。
   - **悬浮语音胶囊与声波光环**：顶部常驻 `🎙️ 开麦中 / 🔇 已闭麦` 与 `🔊 听筒:开 / 🔈 听筒:关` 开关，基于 `AudioContext` RMS 能量检测实时渲染说话方翠绿色声波光环。
   - **BGM 智能音频闪避（Smart Audio Ducking）**：检测到任意一方说话或发送快捷语音时，街机背景音乐自动从 `0.75` 平滑压低至 `0.20`（约 `-8dB`），说话结束 `1秒` 后平滑恢复。
   - **快捷语音喊话（Web Speech TTS）**：内置经典麻将快捷语音，无物理麦克风亦可体验跨窗口实时语音播报与音频闪避。
3. **👆 触控、手势与防误触交互体系（PRD 4.1）**：
   - 支持 **单击选牌**、**按住手牌向上滑动 (`>30px`) 直接出牌**、**双击快出 (`<350ms`)**、**横向滑选高亮**、以及底部右侧 **动态动作胶囊气泡（胡/听/杠/碰/吃）**。

## 🚀 快速启动与联机测试指南

### 1. 安装依赖与启动开发服
```bash
npm install
npm run dev
```
启动后浏览器访问：**`http://localhost:3000/`**

### 2. 测试「四人环桌麻将 (4P)」或「双人死斗 (2P)」
1. 打开 `http://localhost:3000/`，点击顶部右侧橙色按钮 **「🤝 公网/好友联机」**。
2. 在弹窗中选择对局模式：
   - **🀄 四人环桌麻将 (4P 东南西北)**：支持 `1~4 名真人`，未满 4 人时点击底部 **「⚡ 立即开局四人麻将 (X真人 + Y AI补位)」** 即可直接与好友及街机 AI 同桌对战！
   - **⚔️ 二人街机死斗 (1v1 经典)**：点击 **「🖥️ 弹出新窗口测试联机」** 或复制链接发给好友，满 2 人即可开局。
3. **跨公网异地联机**：
   - 异地好友只需打开同一网页，在联机弹窗的 **「🔑 跨公网加入好友房间号」** 输入框中输入您的 **6 位房间号**（如 `884821`）并点击 **「🌐 立即跨网加入该房」**，即可通过公网 WSS 节点秒级入房并连通实时语音。

### 3. 构建生产版本
```bash
npm run build
```
